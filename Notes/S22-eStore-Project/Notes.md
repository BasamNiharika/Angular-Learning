# Libraries and tools used in this project
 - FrontEnd FrameWork: Angular 19
 - Database - MySQL
 - Backend/API - NodeJS
 - Payment Gateway - stripe payment gateway
 - Front Libraries - TailWind CSS 
                   - Font Awesome
                   - RxJS with Signals.
