 ## Observable
 - Observable emit the value from the data stream asynchronously.
 - observer is an object that listens and reacts to the emissions and events generated by the observables.
 - In order to use or access the observable - it has to be subscribed.
   # Subscribing
      - The subscribe() method is used to listen to the data emitted by an observable.
      - subscribe() connects an observer to an observable enabling observer to react to emissions, erros or completion of the observable.
      * There are 3 methods associated with an observer
         1. next()
         2. error()
         3. complete()  //it simples indicates that observable is completed emitting values and reached an end.
                 // Only at end
    # Unsubscribing -- to free up resources
      - Unsubscrubing of observable stops the unnescessary usage of memmory and resources once the process is executed.
      - Essential to prevent memory leaks and unnecessary resource leakage.
      - By unsubscribing we ensure connection between the observable and its subscriber is properly closed when the data or stream is no longer needed.
      - by unsubscribe() method

 ## Async Pipe 
 - async pipe will subscribe to an observable or promise automatically for you and return the last value that was emitted.
 - it automatically check for changes.
 - when the component is destroyed, the async pipe will be automatically get unsubscribed.
 - value$: Observable<number>;
   - common convention in Angular and RxJS
   - indicates that the property holds an Observable.
   - It can be given as value$ or $value.

## Hot Observable and Cold Observable:
 # Cold Observable
 - An observable is called a cold observable when it starts to emit the values only when an observer is subscribed to it.
 - example: Youtube subscription- uniquley behaves for everyone.
 # Hot Observable
 - The Hot observable on the other hand - are the observables that are independent to the subscribers or observers.
 - example: Live telecast,stock updates - same for everyone. // it is also called multi-casting
